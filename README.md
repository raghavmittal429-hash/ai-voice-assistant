# AI Voice Assistant Mobile

Android app built with Kivy. Built automatically with GitHub Actions.

## Download APK

Go to [Actions](../../actions) → Select latest workflow → Download artifact

## Usage

1. Install APK on Android
2. Start Ollama on your computer
3. Enter your computer's IP in app settings
4. Start chatting!
